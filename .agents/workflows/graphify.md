# Workflow: graphify

Follow the graphify skill to build or update the VeriNews developer knowledge graph.

If no path argument is given, use `.` (current directory).
Always respect VeriNews exclusions (`data/`, `models/`, `.venv/`, `.env`, `.next/`, caches) and adhere to `.agents/rules/graphify.md`.
